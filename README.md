# Репозиторий для домашних заданий по курсу "Web-программирование"

В этом репозитории будут размещены домашние задания по курсу "Web-программирование".

## 🚀 Как начать работу

### 1. Форкните репозиторий

1. Перейдите на страницу репозитория GitHub.
2. Нажмите кнопку **"Fork"** в правом верхнем углу.
3. Выберите свой аккаунт GitHub для создания форка.

### 2. Склонируйте свой форк

После создания форка склонируйте репозиторий на свой компьютер:

```bash
git clone https://github.com/alyonashinkareva/web-itmo-2026.git
cd web-itmo-2026
```

### 3. Выполняйте домашние задания

Каждое домашнее задание расположено в отдельной директории.

Рекомендуемая структура репозитория:

```text
web-itmo-2026/
├── hw-01/
├── hw-02/
├── hw-03/
├── hw-04/
└── ...
```

Для выполнения задания:

1. Перейдите в директорию соответствующего домашнего задания.
2. Изучите условие задачи.
3. Выполните задание в соответствии с требованиями.
4. Проверьте работу программы локально.
5. Добавьте изменения в свой репозиторий.

### 4. Сохраните изменения в Git

После выполнения задания добавьте изменения:

```bash
git add .
```

Сделайте коммит:

```bash
git commit -m "added hw2 solution"
```

И отправьте изменения в свой репозиторий:

```bash
git push
```
